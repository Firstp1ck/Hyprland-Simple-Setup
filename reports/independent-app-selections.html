Usage, rollout and remaining limits

  1. Open a group with Enter. Toggle membership with Space. In a multi-select group, press p on a selected app to choose its primary.
  2. Use None for optional GUI editor or dock. Required groups must be populated before starting installation.
  3. Review Application selections before direct shell use. Changing selections updates generated configuration; it does not remove old packages.

Live application windows, notification D-Bus activation, and alternate bar/dock appearance were not tested in a running desktop. Konsole/Pypr matching has source and fixture evidence, not a live window test. Fnott has no implemented DND action; Mako DND requires a corresponding configured mode. ALSA mixers control hardware rather than PipeWire application streams.

Rollback retains the installer's manifest, digest and atomic-write checks. It is not a package uninstall or service rollback. No commit, installation or publication was performed. The code remains in the working tree.

Acceptance: PASS for implementation and automated handoff. A live desktop smoke test remains a rollout task. Browser/mobile/print rendering of this report was not visually inspected; its structural validator is the report check.

Sources and records: canonical plan, usage guide, catalog, review regressions, tofi direct-launch documentation. Installed contract probes used Konsole 26.08.1 and Pyprland 3.4.4 without opening windows.
