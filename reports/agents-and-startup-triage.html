Endpoints and script interfaces were checked against official documentation and downloaded for inspection only. Agent IDs use a separate official source; they never become pacman/AUR package arguments. Only selected agents add their prerequisites. Pi requires Node.js 22.19.0 or newer and npm.

The installer reuses existing executables, otherwise downloads to private run storage with HTTPS-only redirects, bounded retries/timeouts and ambient curl configuration disabled. Scripts run as the normal user with a minimal environment, no controlling TTY, and a 600-second timeout. A successful exit must also produce the expected executable. Optional failures are reported without aborting desktop setup.

Resolved executable paths retain vendor-managed symlinks so self-updates do not pin triage to old versions. Agent PATH entries are managed for Fish and both shipped Hyprland configuration variants. Login, accounts and provider/model selection remain manual.

Startup checks and notification flow

Routing follows the requested available tools: tmux → Zellij → usable Herdr default session → primary terminal. tmux and Zellij get unique incident sessions inside the selected terminal. Herdr gets a new workspace and its exact returned pane; focus happens after dispatch acknowledgement. Ambiguous submissions are not retried.

The snapshot is consumed at most once. Prompt text is passed as data, not shell syntax. Pi uses a read-tool allowlist, Claude/OpenCode use plan modes, Codex uses its read-only sandbox, and Cursor uses ask mode. These controls are not a universal OS sandbox.

Startup checks no longer mistake a closed browser/editor or on-demand launcher for a dead daemon. Shared nwg-panel instances are checked once. Numlock, wallpaper and Dolphin readiness use private current-session markers rather than stale global files. The checker does not restart services or attempt privileged recovery.

Execution-process caveat

A worker reported removing two generated Python cache files through an exact-file fallback after a cleanup command was blocked, before receiving the parent's queued prohibition. That was recorded as a process deviation, not hidden or treated as permission to bypass a guard. Ownership was not independently verified before removal. No further cleanup was authorized; subsequent tests disabled bytecode generation.

Handoff and remaining limits

  1. Open Applications → Coding agents, keep Pi or select alternatives, and choose a primary. None disables integration.
  2. Run setup when you intend to install the selected tools. Complete each agent's account/provider login manually.
  3. On a startup failure, review the notification before clicking its Troubleshoot action. The click shares frozen diagnostic evidence with the chosen agent/provider.

Redaction is best-effort, not a secrecy guarantee. Incident files are private and capped when another incident is published. An unconsumed or uncertain handoff may remain on disk beyond 24 hours until that cleanup occurs, but expired snapshots cannot launch an agent.

Official scripts are mutable third-party code running with user permissions. HTTPS, an endpoint allowlist, cleared installer environments and timeouts do not create an OS sandbox or pinned supply-chain verification. Vendor-managed installations are outside configuration rollback; deselection does not uninstall them.

Live notification actions, terminal/mux compatibility and provider authentication were intentionally not exercised. The report's responsive/print structure is validated, but no browser visual inspection was performed. Prior repository changes were preserved; no commit or publication was made.
