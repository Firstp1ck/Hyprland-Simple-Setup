Usage and remaining limits

  1. Open Applications → Multiplexer. Use Space to select members and p to make a selected member primary. Installation stays blocked while this required group is empty.
  2. Run setup when you intend to install and apply the choices. Ctrl+Y then opens the selected primary multiplexer in the primary terminal.
  3. For startup triage, configure your selected coding agent separately. Launch occurs only after clicking the notification action.

Custom bindings need attention if they prepend a terminal to apps.multiplex or $multiplex. These values now contain the full terminal action. Execute them directly. Setup migrates exact former stock bindings, but does not rewrite custom variants.
